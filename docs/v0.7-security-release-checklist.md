# OpsPilot V0.7 安全发布检查清单

> Language: 简体中文（当前） | [English](./v0.7-security-release-checklist.en.md)

本文档记录当前实现状态，用于 V0.7 发布前安全复核。

## 安全配置

| 检查项 | 状态 | 证据 |
| --- | --- | --- |
| 生产环境默认关闭公开注册 | 完成 | `APP_ENV=prod` 时需要显式配置 `AUTH_PUBLIC_REGISTRATION_ENABLED=true`。 |
| 生产 JWT secret 校验 | 完成 | 生产环境会拒绝空值、默认开发值和过短 secret。 |
| CORS allowlist | 完成 | Origin 按配置 allowlist 匹配。 |
| Agent token 边界 | 完成 | Agent opaque token 只允许访问 Agent 私有接口。 |
| 用户 JWT 边界 | 完成 | 用户 JWT 不能访问 Agent 私有执行接口。 |
| Webhook token 边界 | 完成 | Trigger token 只定位 source；HMAC 使用独立 signing secret。 |

## 敏感数据处理

| 表面 | 预期行为 |
| --- | --- |
| Logs | `security.Redact` 遮盖 bearer token、token/password/secret/authorization 类字段。 |
| Audit logs | `audit.Write` 在写入前脱敏序列化后的 `before`、`after`、`metadata`。 |
| Notification channel list | 不返回 channel config 明文；UI 只接收 `targetSummary`。 |
| Webhook source creation | Trigger token 和 signing secret 只在创建时返回一次；列表不返回 secret。 |
| Agent enrollment token | 完整 token 只在创建时返回；列表只返回 token prefix。 |
| SMTP config | 本地 `.env` 被 git 忽略；示例文件只记录变量名，不包含真实凭据。 |

## 审计覆盖

| 领域 | 已审计动作 |
| --- | --- |
| Auth | Login、logout。 |
| Users/Roles | 角色权限更新。 |
| Agents | 注册、禁用、token 撤销、enrollment token 创建/撤销。 |
| Scripts | 创建、更新、禁用、审批申请、approve/reject。 |
| Tasks | 创建和取消 task run。 |
| Schedules | 创建和状态变更。 |
| Webhooks | Source 创建/状态变更、rule 创建/更新/状态变更。 |
| Alerts | Rule 创建/更新/状态变更、ack、silence、unsilence、resolve。 |
| Notifications | Channel 创建、测试发送、delivery 重试。 |
| Audit Logs | 审计日志检索与详情查看受 `audit.read` 保护。 |

## 发布验证命令

打 V0.7 tag 前必须执行：

```powershell
cd server
go test ./...
go vet ./...
cd ..\web
npm run build
cd ..
powershell -File .\scripts\migration-check.ps1 -SkipExecution
```

Docker 可用时还需要执行：

```powershell
docker compose -f deploy/docker-compose.yml --profile full config
docker build -f server/Dockerfile .
docker build -f web/Dockerfile .
```

## 剩余风险

| 风险 | 后续处理 |
| --- | --- |
| 本地 Windows 环境之前不可用 Docker 验证。 | 依赖 CI，并在 Docker CLI 可用的环境复测。 |
| Notification channel config 仍以 JSON 存储。 | 保持 API 遮盖和审计脱敏，后续版本考虑加密存储。 |
